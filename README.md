# HolidayMate AI

A responsive Next.js starter for an India + worldwide holiday discovery and planning experience.

## Features
- Responsive travel landing page
- Search destinations and filter demo holiday packages
- Package detail dialog and demo trip-request form
- Indicative INR prices and sample destinations
- Ready for Vercel deployment

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy to Vercel
1. Import this GitHub repository in Vercel.
2. Framework preset: Next.js.
3. Build command: `npm run build`.
4. Deploy.

## Important: demo only
This repository currently contains a frontend prototype. Package data and prices are sample content. The request form does not save data or create a reservation. No live flight/hotel inventory, supplier integrations, user accounts, database, AI assistant, or payment processing is connected.

Before accepting real bookings, add a secure backend/database, authentication, a licensed travel inventory provider, booking confirmation workflows, customer support, and a compliant payment integration. Never collect or store card details directly in this frontend.
